# InkTalk 0.5.2 内屏与手写体验优化说明

## 修正内容

- 宽屏输入法内容上限从 `720dp` 增加到 `900dp`。
- 中等宽度控制区保持 `340dp`；展开宽度控制区增加到 `380dp`。
- 宽屏语言模式旁增加左右交换按钮，可将输入内容区移动到左侧或右侧。
- 左右顺序保存在本地设置中，下次打开输入法继续使用。
- 手写候选词栏从画板底部移动到画板顶部，并始终保留固定高度，避免候选出现或消失时画板跳动。
- 中文和英文手写模型并行识别，候选自动合并，不再需要手动切换语言。
- 手写提示移入画板中央；语音按钮由 `64dp` 缩小为 `56dp`。

## 首次在内屏打开的修正

此前输入法只在创建后执行一次宽度计算。部分折叠屏直接在内屏创建 IME 时，第一次计算可能拿到尚未布局的宽度或旧的外屏配置，因此仍显示横向拉伸的手机布局；外屏切换内屏会触发配置变化，所以第二条路径可以进入宽屏布局。

0.5.2 增加以下重新计算入口：

- 输入法根 View 的真实尺寸发生变化；
- 输入法窗口显示；
- 输入视图开始；
- 系统配置变化。

布局判断优先使用根 View 实际测量宽度。直接在内屏唤出输入法时，不再依赖先经过一次外屏配置变化。

## 复测重点

- 完全关闭输入法后，直接在内屏打开目标 App 并唤出 InkTalk，应立即显示左右分区。
- 点击语言模式旁的交换按钮，两个区域应交换左右位置；重新唤出输入法后顺序保持。
- 手写识别产生候选词后，候选词应显示在画板上方，画板位置不应变化。
- 分别书写中文和英文，候选栏应同时覆盖两种文字，不显示语言切换按钮。
- 外屏或窄分屏应继续显示手机纵向布局。
- 展开、折叠和左右交换不应中断或提交当前语音、指令、手写和数字输入状态。

静态测试和构建不能替代真实折叠屏上的窗口、触控和宿主输入验收。
