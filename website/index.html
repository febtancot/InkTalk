Android 语音输入法

按住说话，
文字实时上屏。

InkTalk 是一款以语音为核心的 Android 输入法，基于火山引擎「豆包流式语音识别大模型 2.0」， 支持中英混合识别、自由语音指令、手写输入，并可接入任意 OpenAI 兼容大模型完成总结、翻译与整理。 它没有键盘——我们取消键盘，就是希望让你纯粹地享受语音输入带来的高效。

设计理念

没有键盘，是刻意的

取消键盘不是做减法，而是把「说、写、改、理」四件事交给最合适的方式：语音负责速度，手写负责精度，指令负责改写，每日整理负责回顾。它们彼此配合，构成一条完整的输入闭环。

①

语音速记

按住即说、实时上屏，思考的速度就是成文的速度。长文、灵感、消息，先说出来再说。

②

手写精修

手写与语音默契配合：手写负责精准定位与补字，语音负责说出改法——这是局部修改的最佳方案，不改全文，只动该动的地方。

✦ 指令改写

AI 辅助改写是语音输入的必要搭档：口述难免口语化，一句指令就能润色成稿。输入法由此成为一个随身的小型 AI Chat 入口。

→
④

每日整理

一键梳理当日全部语音、手写与指令输入，AI 生成当日摘要——高效回顾一天输入内容的最佳方案，也是 InkTalk 最大的特点之一。

功能

一块键盘，覆盖从听写到成稿

语音是主线，AI 与手写是补充。所有功能都在输入法面板内完成，不需要离开当前应用。

低延迟实时听写

双向流式端点（bigmodel_async），200 ms 音频分包，识别结果只在变化时下发；边说边上屏，结束自动定稿。

四种输入模式

中文、实时中英混合、数字口述（自动规整为阿拉伯数字）、英文优先定稿（en-US），一键切换，随说随换。

✦ 自由语音指令 · 你的 AI Chat 入口

说出修改要求即可改稿：支持选区修改、全文修改与光标处生成。结果先在面板预览，确认后才写入——输入法从此也是一个随身的 AI Chat。

AI 总结 / 翻译 / 整理

优先处理选中文本，未选中时处理本次语音内容。接入任意 OpenAI 兼容 API，结果可追加或直接替换原文。

手写输入 · 语音的精修搭档

基于 ML Kit 数字墨迹识别，支持简体中文与英文，模型按语言下载后离线可用。与语音配合，是局部修改的最佳方案：手写定位，语音改法。

⌘ 快捷键面板

ESC、Tab、全选、复制、粘贴、撤销（Ctrl+Z）与方向键，5×2 等宽网格，横向滑动切换，编辑长文不求人。

每日输入记录 · 当日整理

语音、手写、指令与 AI 结果按日期归档在本机，一键「整理当日内容」即可让 AI 生成当日摘要——高效梳理一天所有输入，InkTalk 最大的特点之一。

热词与参数控制

专有名词热词提升识别准确率；智能标点、数字规整（ITN）、语义顺滑（DDC）均可在设置中独立开关。

配置导入导出

语音识别、AI 与输入模式配置可导出为 JSON 备份、换机导入，单文件上限 128 KB，导出前提示敏感凭据风险。

原理

两段式架构：先听清，再写好

语音识别与 AI 处理相互独立，均可自由替换服务方，凭据只保存在本机。

① 语音识别 · 火山引擎

豆包流式语音识别大模型 2.0（SAUC 二进制协议，WebSocket + gzip）。16 kHz 单声道 PCM 以 200 ms 分片上行，async 端点专属二遍识别负责最终定稿；单次会话最长 120 秒，超时自动结束。

→

② AI 处理 · 任意 OpenAI 兼容接口

总结、翻译、整理与语音指令走标准 chat/completions。可配置 Base URL、API Key 与模型名；「关闭思考模式」开关自动适配通义、火山方舟豆包与 OpenAI gpt-5 系三类参数。

快速开始

三分钟完成配置

需要火山引擎「豆包流式语音识别大模型 2.0」凭据（按音频时长计费）；AI 功能为可选项。

  1. 三步引导安装后打开设置页，依次完成：启用 InkTalk 输入法 → 切换到 InkTalk → 授予录音权限。
  2. 填入凭据新版控制台只需填 API Key；旧版控制台填 App ID + Access Token。点「测试 ASR 连接」，成功会返回 logid。详细获取步骤见配置指南。
  3. 开始使用在任意输入框唤出 InkTalk，选好模式后点大麦克风说话，再点一次结束上屏。需要改稿时点 ✦ 说出指令，预览确认后替换。

隐私与安全

凭据不出机，敏感场景自动回避

本机存储

API Key、App ID、Access Token 只存本机 SharedPreferences，应用不内置任何密钥；每日输入记录仅追加保存在本机数据库，整理结果单独保存、不覆盖原文。

敏感输入框保护

密码、PIN 等敏感输入框中禁用指令模式，也不会写入每日记录；宿主无法提供完整文本时，指令模式拒绝执行，不会把残缺上下文当作全文。

写入前校验

AI 与指令结果写入前会复核选区、光标与原文；任一发生变化即取消写入，避免误删。指令模式单次完整上下文上限 6,000 字符。

触觉反馈遵循系统

麦克风、模式切换与快捷键使用 Android 原生触觉反馈，自动遵循系统「触摸反馈」开关，不额外申请震动权限。

已知限制

使用前请了解

  • 语音识别单次会话最长 120 秒，超时自动结束。
  • 「实时中英混合」不严格过滤中文；「英文优先定稿」仍可能返回中文内容。
  • 指令模式依赖宿主应用提供完整文本与选区，部分应用可能不支持。
  • 快捷键面板的「撤销」发送 Ctrl+Z 按键事件，是否生效取决于目标应用。
  • 识别参数（采样率 16 kHz、endpointing 800 ms）为固定推荐值，暂未全部开放。
  • 部分 AI 提供方对「关闭思考模式」参数报 400，此时请关闭开关或改用非思考模型。
